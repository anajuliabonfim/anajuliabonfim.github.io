# anajuliabonfim.github.io

My personal website: **[anajuliabonfim.github.io](https://anajuliabonfim.github.io)**

A one-page portfolio with my experience at Rizoma, the tools I use and how to reach me, in English and Portuguese.

## Features

- Interactive terminal (try `whoami`, `experience`, `stack`)
- English / Portuguese switch, saved in the browser
- Typing effect, counters and scroll reveal
- Card tilt and a glow that follows the pointer
- Stack filter by category
- Responsive layout and `prefers-reduced-motion` support

## Built with

HTML, CSS and JavaScript, no frameworks. Hosted on GitHub Pages.

## Project structure

```
index.html   page markup
style.css    layout and theme
content.js   text in English and Portuguese
script.js    interactions
icons.js     stack logos (Simple Icons)
```

## Running locally

Open `index.html` in the browser, or use the Live Server extension in VS Code.
